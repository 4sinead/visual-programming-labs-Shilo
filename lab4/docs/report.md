## Часть 1. Установка и запуск n8n

**Способ установки:** npm (Docker на компьютере не работает из-за конфликта виртуализации с VMware и ошибки 0x80073712).

**Версия n8n:** vX.X.X *(замени на свою)*  
**Версия Node.js:** vX.X.X *(замени на свою)*

**Запуск:**
```bash
npm install n8n -g
n8n start
```

Приложение доступно по адресу `http://localhost:5678`.
